The saved [MAP listing](../../../../../resources/sampler-140626/test/Entity_resolution_Relation/all-poss-facts/output-2500/map_world.txt), [logprobs trace](../../../../../resources/sampler-140626/test/Entity_resolution_Relation/all-poss-facts/output-2500/logprobs.txt), [relation trigger listing](../../../../../resources/sampler-140626/test/Entity_resolution_Relation/all-poss-facts/output-2500/relation_triggers.txt) and [entity mention listing](../../../../../resources/sampler-140626/test/Entity_resolution_Relation/all-poss-facts/output-2500/entity_mentions.txt) are companion views of one output family. The [archive comparison](../../../../../resources/sampler-140626/results/nyt-2026/evaluation/archived_comparison.md) identifies input [pluieTriples_fgreptest4.json](../../../../../resources/sampler-140626/data/06-19/pluieTriples_fgreptest4.json) by triple-multiset matching, not merely folder naming.

The input has 2,500 rows. The MAP text has 50 relation headers and 2,461 displayed sentence occurrences; it omits 39 occurrences, while its path histograms total 2,500. The imported observer stops gathering examples at ten distinct facts per relation/path; there are no extra source triples. The stored trace contains 10,000 values in each of five channels (total, facts, args, origin, collapsed_trigs). The first MAP value -438332.14352157287 equals max(total); the final total is -438408.5692874451. Equality with the archived score trace does not establish that the score was the intended full joint.

The mention listing prints 1000 entity headers. These are output counts, not proof of the initial configuration. Exact alpha/beta, sparsity, schedule, relation capacity, initialization and seed are unknown. Multiple noun strings can share archived entity IDs; this is not evidence of a verbatim/frozen entity experiment. The later config-250-inferK.json and config-8000.json do not identify this run's settings.

The files were imported with the June-2014 archive; no exact command, seed or source snapshot binds them to a producing revision. Archive code had an incomplete relation joint and entity/state/proposal/normalization defects, as documented in [CHANGES](../../../../../resources/sampler-140626/CHANGES.md) and [the code audit](../../../../../resources/sampler-140626/results/nyt-2026/evaluation/code_audit.md). Their impact on this individual earlier output is not recoverable. These outputs predate the update's inferred-count prior and newly introduced fact-deletion move; they are not evidence for the corrected 2026 sampler.

No contemporaneous complete semantic annotations or precision/recall score are saved in this directory. The existing comparison's 516/2461 multiset intersection with the full 2026 NYT TSV is corpus overlap, not fact precision, recall or partition agreement. The truncated display cannot reconstruct a complete row partition.

The later [archive-scope analysis](../../../../../experiments/nyt-complete-evaluation-2026-09-14/analysis/archive_scope.md) counts 2,401 displayed MAP facts; the top 20 have 1,137 histogram rows but only 1,107 printed rows and 1,070 displayed facts. A census of those 1,070 would not cover the unknown complete top-20 population. The neighboring trigger listing is a different state (2,465 rows, 2,408 displayed facts); its rows cannot repair omissions in the MAP. No complete semantic census was therefore reported for this archive.

Current role: historical 2500-row output with trace and corpus provenance evidence, not the documented 2026 pool-150 scaling run. No inference, tests or cleanup were performed.
